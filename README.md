# LevelUp

LevelUp 是一个无需注册、无需登录的个人成长管理网站，帮助你设定目标、安排任务、记录日常，并回顾自己的成长。

在线体验：[levelup-growth.pages.dev](https://levelup-growth.pages.dev/)

## 网站功能

- **成长概览**：查看进行中的目标、今日完成任务、日志篇数和近 7 天活跃情况。
- **目标管理**：创建和编辑目标，设置成长领域与截止日期，标记完成或重新开启，支持状态筛选和回收站恢复。
- **日常任务**：创建独立任务或关联已有目标，安排计划日期，标记完成、重新开启，按日期和状态筛选。
- **成长日志**：按日期记录收获与感受，补写历史日志，编辑内容，搜索标题或正文，查看指定日期的记录。
- **成长统计**：查看最近 7 天、30 天和全部活动，展示任务与日志趋势、活跃天数，以及当前目标完成率和领域进度。
- **数据备份**：导出包含寄语、目标、任务、日志及回收站的完整备份，支持导入预览与恢复；导入后尚未继续编辑时可撤销。
- **匿名与本地保存**：个人数据保存在自己的浏览器中，无需账号；支持通过备份文件迁移记录。
